# Trabajo colaborativo

- `main`: versión estable.
- `feature/nombre`: nueva funcionalidad.
- `fix/nombre`: corrección.
- `docs/nombre`: documentación.

Flujo:
1. Crear una rama desde `main`.
2. Realizar cambios y probarlos.
3. Hacer commit con mensaje claro (`feat: agregar consulta de comandas`).
4. Subir la rama y abrir un Pull Request.
5. Solicitar revisión de otro integrante antes de fusionar.

No subir contraseñas, tokens, cadenas de conexión reales ni datos de clientes.
